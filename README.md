# 📓 دفتر يوميات GitHub Pages — PAT + تشفير كامل

موقع ثابت (عربي RTL) + نشر تلقائي عبر GitHub Actions. الدخول بـ PAT + كلمة سر تشفير، محفوظان في **localStorage بهذا المتصفح** (يبقى بعد الإغلاق).

## 🔑 الدخول
1. الصق PAT بصلاحية **Contents: Read and write** → **📦 عرض مستودعاتي** → اختر الريبو من القائمة (فقط ما لديك عليه كتابة).
2. أدخل **كلمة سر التشفير** (4 أحرف على الأقل، والأفضل قوية) → **دخول**.
3. نفس الكلمة مطلوبة كل جلسة. **نسيانها = ضياع البيانات نهائياً** (لا استرجاع).

## 💾 بقاء الدخول (localStorage)
- الـ PAT وكلمة السر والريبو تُحفظ في **localStorage بهذا المتصفح** وتبقى بعد إغلاقه — لا حاجة لإعادة الإدخال.
- ⚠️ هذا يعني أن من يفتح متصفحك يصل للدفتر: استخدمه على **جهازك الخاص فقط** مع قفل شاشة. للمسح الكامل اضغط **🚪 خروج** (يمسح الدخول المحفوظ).
- ملفات العرض (المصغّرات والملفات المفتوحة) تبقى **RAM فقط** وتُمسح بالإغلاق حسب سياسة الذاكرة أدناه — الدائم هو بيانات الدخول فقط.

## 🔐 التشفير (كل البيانات مهما كانت)
- المفتاح: `PBKDF2-SHA256 (120,000 تكرار) + AES-GCM-256`، يُشتق من كلمة السر + ملح محفوظ في `data/crypto.json` (الملح علني وهذا آمن).
- **النصوص**: ملف `data/entries.json` كله مشفّر بصيغة `{"v":1,"iv","data"}` — لا عنوان ولا نص ولا تاريخ مقروء في الريبو.
- **الصور/الفيديو/الصوت**: تُحزم مرفقات اليومية في أرشيف **ZIP واحد** يُشفّر (`IV || ciphertext`) ويُرفع `media/DATE/TIMESTAMP.zip.enc` — لا معاينة بدون كلمة السر حتى لمن يملك الريبو.
- كلمة السر والمفتاح في الذاكرة + `sessionStorage` فقط، ويُمسحان بزر **خروج** أو إغلاق التبويب.

## 🖼️ العرض: مصغّرات بدون تحميل
- وقت الرفع تُولّد **مصغّرات**: صورة 320px للصور، **إطار من الفيديو** + مدته، ومدة الصوت — وتُخزن داخل اليومية المشفرة.
- تصفح القائمة والتقويم **لا يجمّل أي ملف**: المصغّرات تظهر فوراً من `entries.json` (محمّلة أصلاً).
- **كل ملف مخزن مشفراً وحده** (`media/DATE/TIMESTAMP_NAME.enc`) — الضغط على المصغّر يجمّل **هذا الملف وحده فقط**، لا حزمة اليوم كاملة. زر **▶ تحميل الكل** يجمّل مرفقات اليومية دفعة واحدة.

## 🧠 سياسة الذاكرة (RAM فقط — لا قرص إطلاقاً)
- **المرفوعات**: تُزال من الذاكرة **فور نجاح الحفظ** (المصغّرات تكفي للعرض).
- **المحملة للعرض**: تُحذف تلقائياً **بعد 24 ساعة** من فتحها (فحص كل 15 دقيقة + عند الوصول) — لا لحظياً ولا للأبد.
- الخروج يمسح الدخول المحفوظ والذاكرة فوراً. إغلاق التبويب يمسح الذاكرة فقط ويُبقي الدخول.

## ⏳ الرفع والإغلاق
- **لا يستمر الرفع بعد إغلاق المتصفح** — مستحيل تقنياً في موقع ثابت (تتوقف كل السكربتات).
- المغادرة أثناء الرفع تُظهر **تحذيراً** قبل الإغلاق.
- الانقطاع لأي سبب ثم ضغط **حفظ مجدداً يُكمل من حيث توقف**: مسار كل ملف ثابت، والمرفوع فعلاً يُتخطى بدل إعادة رفعه (لا تكرار).

## 📥 العمل دون إنترنت (قائمة انتظار)
- الحفظ يعمل دون اتصال: اليومية + ملفاتها تُحفظ في **IndexedDB على هذا الجهاز** (تبقى بعد إغلاق المتصفح) وتُرفع **تلقائياً** عند عودة الإنترنت (زر **↻ رفع الآن** لليدوي، و🗑 للحذف من القائمة).
- تُشفّر الملفات قبل تخزينها محلياً متى أمكن (الملح محفوظ محلياً بعد أول اتصال). الاستثناء الصادق: أول استخدام **دون أي اتصال سابق** يُخزن خاماً على جهازك حتى لحظة الرفع حيث يُشفّر — جهازك الخاص فقط.
- لا تعمل المزامنة قبل تسجيل الدخول (تحتاج PAT + كلمة السر).

## ✏️ اسم وملاحظة لكل ملف
- تحت كل ملف مرفق في صفحة الرفع: حقل **اسم العرض** (يظهر بدل اسم الملف الأصلي ويُستخدم عند التنزيل) وحقل **ملاحظة** (تظهر مع المصغّر وتحت العرض الكامل).
- يُحفظان مع اليومية المشفرة، ويظهران في قائمة الانتظار أيضاً.

## 🗜️ الضغط والرفع
- **الصور**: ضغط تلقائي (تصغير لأقصى 1920px + JPEG جودة 0.82) قبل التشفير.
- **الرفع**: كل ملف يُشفّر ويرفع وحده `media/DATE/TIMESTAMP_N_NAME.enc` — الحد **60MB للملف، 150MB لمجموع اليومية** (حدود GitHub API).
- **⬇️ تنزيل ZIP**: زر تنزيل يجمع ملفات اليومية في ZIP صالح مفكوك التشفير (للنسخ الاحتياطي).
- **بصراحة**: لا شيء يصغّر JPEG/MP4 كثيراً (مضغوطة أصلاً) — التوفير من ضغط الصور. **RAR مستحيل** داخل المتصفح (صيغة مملوكة بلا مشفّر JS) و**7z غير عملي** (LZMA ثقيل) — وZIP المستخرج عند التنزيل يفتح في كل الأنظمة بدون برامج.
- **الفيديو/الصوت**: لا ضغط تلقائي — قلل الجودة قبل الرفع. التسجيل الصوتي من الموقع مضغوط أصلاً (WebM).

## 🚀 التشغيل
```powershell
cd D:\Snono-Dev\GHjournal
git init; git branch -M main
git add .; git commit -m "journal: encrypted"
gh repo create GHjournal --private --source=. --push
```
1. الريبو → **Settings → Pages → Source: GitHub Actions**
2. Fine-grained PAT على **هذا الريبو فقط** → Contents: **Read and write**
3. افتح `https://USERNAME.github.io/GHjournal/` → PAT → اختر الريبو → كلمة السر → دخول

## 📁 البنية
```
index.html   دخول (PAT + كلمة سر) + الدفتر + قائمة انتظار (مكتبة ZIP عبر CDN)
js/app.js    كتابة + PBKDF2/AES-GCM + ضغط الصور + مصغّرات + رفع فرادى + تنزيل ZIP + انتظار دون إنترنت (IndexedDB) + أسماء وملاحظات الملفات + تقويم/بحث/تسجيل
data/crypto.json    الملح (علني)
data/entries.json   اليوميات مشفرة بالكامل
media/.../*.enc        ملفات مشفرة فرادى (ملاحظة: حزم .zip.enc القديمة ما زالت تُقرأ)
```
